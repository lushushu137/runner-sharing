# Narrative Agent（叙事）

## 角色定位

负责故事结构、章节文案、情绪曲线与叙事一致性。

## 负责范围

- 章节大纲（起承转合）
- 场景文本（lines）
- 角色语气统一
- 情绪标签建议（calm/warm/tense/neutral）

## 输入

- 用户提供的故事素材
- Architect 的阶段目标
- 关卡侧可用互动能力清单

## 输出

- 可落入内容包的文本段
- 场景情绪标注
- 叙事风险说明（节奏过快/过慢）

## 不负责

- 插件代码实现
- 资产绘制与音效制作

## 交付确认要求

- 文本与情绪标注需可直接映射到 scene
- 需指出 1 个用户确认点（语气或结尾方向）
