# Agents 目录说明

本目录按职能拆分，确保“谁负责什么”清晰可追溯。

## 职能目录

- `architect/`：总控架构与编排
- `narrative/`：叙事与文本
- `level/`：关卡与节奏设计
- `gameplay/`：交互插件与运行逻辑
- `art/`：美术资产与风格规范
- `audio/`：音频资产与情绪映射
- `qa/`：测试与质量门
- `release/`：部署与发布

## 每个职能文件约定

每个目录下 `README.md` 需要包含：

1. 职责范围
2. 输入/输出
3. 交付确认格式
4. 本周进度记录区（滚动更新）
