# 协作协议（Collaboration Protocol）

## 生命周期

每个任务遵循以下状态：

`draft -> in_progress -> ready_for_review -> waiting_user_confirm -> done`

## 职责边界

- 未被指派的角色不得直接修改他人职责范围核心内容
- 跨职能修改必须在输出中说明原因与影响面
- 任何“非预期改动”都要单独标注

## 强制确认点

以下阶段必须向用户发确认：

1. 叙事大纲冻结前
2. 关卡参数冻结前
3. 首轮美术风格冻结前
4. 上线前（QA 通过后）

## 交接要求

每次交接必须包含：

- 输入：本轮使用的上下文文档
- 产出：具体文件路径
- 风险：已知问题与影响
- 请求：需要用户确认的一条核心问题

## 变更可追溯

- 决策变化需写入对应职能目录
- 重要规则变更同步更新 `docs/session-context.md`
