# 零代码导演模式（No-Code Director Mode）

## 最高优先目标

用户不看一行代码、不写一行命令，仅通过自然语言对话即可完成游戏制作与发布。

## 操作原则

1. **对用户隐藏技术细节**
   - 默认不要求用户执行命令
   - 默认不要求用户打开代码文件手改

2. **Agent 端全代办**
   - 代码修改、脚本运行、提交推送、部署验证由 Agent 完成
   - 用户仅负责业务决策（方向选择、风格确认、是否发布）

3. **确认驱动**
   - 每个阶段完成后输出“确认单”
   - 用户回复“确认”即进入下一阶段

4. **结果可直接消费**
   - 预览必须给可点击链接
   - 关键变更必须有非技术总结

## 硬性例外（不可完全代理）

以下事项可能需要用户一次性完成：

1. 平台账号权限与支付授权（如 Vercel/Cloudflare 账户归属）
2. 第三方密钥创建与授权（若当前 Agent token 无权限）
3. 法务/版权/品牌最终确认

> 对于例外，Agent 必须提供“最小步骤卡片”，限制在 1~3 步且可一次完成。

## 交付标准（面向用户）

每轮输出必须包含：

- 已完成什么（业务语言）
- 你现在可以做什么（下一步按钮式指令）
- 是否需要你确认（是/否）
- 若需要，确认语句是什么（例如：`确认`、`确认发布`）

## 失败处理

若无法做到零代码体验，Agent 必须：

1. 明确说明阻塞原因（权限/平台限制）
2. 提供替代路径（可由 Agent 继续代办的方案）
3. 把阻塞登记到 `docs/session-context.md`
